## デザイン要素の適用

### 共通要素
- **カード**: 丸い角（border-radius: 20px）
- **区切り**: 波線SVGまたはCSS
- **セクション**: 曲線背景（border-radiusまたはSVG）
- **ラベル**: シール風（丸い背景、影付き）
- **感覚**: 手作り感（不規則な配置、手書き風フォント）

### 写真優先レイアウト
- ヒーロー: 写真80% / テキスト20%
- 人気個体: 写真70% / テキスト30%
- 新種発見: 写真80% / テキスト20%
- 観測ログ: 写真60% / テキスト40%
- 譲渡局: 写真70% / テキスト30%

### 全体平均: 写真72% / テキスト28%

## レスポンシブ対応

### ブレークポイント
- PC: 1024px以上
- タブレット: 768px-1023px
- スマホ: 767px以下

### 変更点
- PC: 4列グリッド
- タブレット: 2列グリッド
- スマホ: 1列グリッド
- ヒーロー写真サイズ: PC80% / タブレット90% / スマホ100%
