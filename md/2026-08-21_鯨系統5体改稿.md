# 2026-08-21 鯨系統5体の改稿

対象：
No.013 白鯨／No.014 黒鯨／No.015 メタル白鯨／No.016 金鯨／No.019 もち鯨
（`astro-src/src/content/creatures/` 配下の各 `index.md`）

変更前の前提：
鯨系統5体は「棚水圏」を habitat とし、深海極圧環境・高圧噴流など海洋生物的な
設定で記述されていた。danger も 80／75／56／70 と高めに設定されていた。

変更後の内容：
- habitat を「棚水圏」から「腰水域」（水面／深部／沈殿層／底層の階層）に変更
- 本文をすべて、背中に載せたアガベの小株に水と光を届けるための個体、という
  共通設定で書き直し
- danger を大幅に引き下げ（013: 80→15／014: 75→20／015: 56→25／016: 70→20／
  019: 20→10）
- No.013・015 の status_label をそれぞれ変更
  （013: MYTHIC/神話級→ACTIVE/活性状態、015: MONARCH/支配個体→STABLE/安定状態）
- No.019 もち鯨は「環境で変色する」設定を撤廃し、桃・緑・白の3個体が
  生まれつき固定色という設定に変更

理由：
`oldno07/jarvis-core` 側でカバー画像を実測した結果、5体はいずれも手のひらに
乗る丸く柔和な造形で、背中に緑と白のアガベの小株を載せた共通の意匠を持つと
判明した。従前の「深海極圧環境」「海底を削る高圧噴流」等の記述は造形と対応
しておらず、danger も見合わなかったため、jarvis-core の DEC-20260810-016〜020
（PR: `oldno07/jarvis-core` #26）に基づき本文・パラメータを全面的に作り直した。

  今回の改稿対象（本文markdown 5体）には含まれておらず、修正はしていない。
  対応が必要であれば別タスクとして扱うこと。
- No.019 の `notes` には「植物棚の水場」という旧表現が残っているが、
  指示により本改稿では変更していない。
