# 通知メール配信元情報リンク確定

## 対象
Brevo 経由の通知メールテンプレート実装時の「配信元情報」セクション

## 確定内容
配信元情報のリンク先：**https://pelicanworks.site/privacy/**

## 実装時の文言例
```
4K WORKS｜配信元情報：pelicanworks.site/privacy/｜配信停止：[unsubscribeリンク]
```

## 背景
- プライバシーポリシーページ（/privacy/）を 2026-07-29 に新設
- 通知システム仕様書 v1 では配信停止リンクのみ記載されていたが、
  配信元情報（特定商取引法対応）として企業情報・プライバシーポリシーリンクが必要になった
- メールテンプレート実装は通知システムの次フェーズとなるため、
  リンク先を事前に確定して記録する

## メール実装時の参照
`md/通知システム/仕様書.md` 参照。
Brevo テンプレート設計時に本記録の URL を適用。
